# 字体不随仓库分发

预览和渲染时，页面从这里加载：

`_fonts/SJcaoquanbei.ttf`

这是「三极曹全碑隶书简」，版权属于三极字库，属于商业字体。本仓库不包含这个文件，也不包含任何 `.ttf` / `.otf`。请自行取得字体，放到上面的路径。文件名必须是 `SJcaoquanbei.ttf`。

商业使用需要你自己持有相应授权。即便只在本地查看粗剪，也请先确认许可允许这种用途。

没有这套字体时，页面会退回系统里的中文字体，无头截帧仍然可以出图，只是碑文体的标题不会像成片。程序生成的隶书笔画（`glyphs_lishu.js`）不读取这个字体文件。

嵑、夐二字由笔画数据拼出，见 `glyphs_lishu.js` 里的 `LISHU_COMPOSED`。
