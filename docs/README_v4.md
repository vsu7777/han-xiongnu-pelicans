## v4 改动
- 南匈奴联军（汉军盟友）由“人骑马”改为**鹈鹕骑 26 寸女式坤车**：车架为低位双斜梁，没有横梁；带藤编前车筐、全包链罩、挡泥板、后货架和宽软鞍座；车漆米白（#e8e0cc）。鹈鹕戴皮帽、穿左衽皮袍、颈系红巾，部分举红底「南」字旗。北匈奴保持黑色二八大杠单车阵，没有车筐和红巾。
- 坤车沿用同一套 rig：五通、曲柄长和鞍座高度与二八大杠相同，所以脚踏 IK 用的是同一个 legSolve 函数，脚始终在踏板上。车轮半径为 87（26/28×94），齿比仍为 2.5；轮转角 = 行进距离/87，曲柄转角 = 轮转角/2.5，链速与飞轮匹配。为了让小轮落地，整车下移 7 单位。数值校验见 check_v4.json：pelHorse.bike26WheelCrankErr ≈ 7e-12，bike26ChainMismatch ≈ 9e-13，rig.footSoleOnPedalTopMaxErrPx = 0。
- 汉军骑兵分前、中、后三层（y 792 / 872 / 990，比例 .22 / .34 / .55），层内间距拉开。
- 被冲翻的单车先抛起翻滚，再落地（倒扣或扶正）、弹一下、滑停；脱落的车轮滚动减速，停住后倒下。
- 被冲散的北匈奴鹈鹕跳车落地后向西（画面左侧）步行逃离，约 40% 扶正单车推着走（车轮按行进距离转动，不打滑），接 4-1 的西迁步行。
- 片头副标题改为「四幕 · 十七镜 · 粗剪 v4」。
- 音效：时长和事件时点都没变，因此原样沿用 v3 的 WAV（逐字节相同）。网盘版实测 -17.4 LUFS。
